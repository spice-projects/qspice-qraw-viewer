# PyQSPICE QRAW test files

Sample `.qraw` files used for parser testing and development.

## Files

| Circuit | File | Description |
|-------|------|-------------|
| 10_DC | `UJ3N065080.qraw` | UJ3N065080 component simulation |
| 20_AC | `VRM_GainBW.qraw` | Voltage regulator module gain/bandwidth analysis |
| 22_NyquistDia | `VRM_Nyquist.qraw` | Voltage regulator module Nyquist analysis |
| 30_TRAN | `Buck_COT_TRAN.qraw` | Buck converter transient analysis |
| 40_Bode | `Buck_COT_Bode.qraw` | Buck converter Bode plot analysis |
| 50_OP | `op.qraw` | Operating point analysis |
| 70_VerilogBus | `VerilogBus.qraw` | Verilog bus simulation |
